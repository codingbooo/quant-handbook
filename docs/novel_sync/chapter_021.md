# 第 21 章 战长沙关黄对决，斩韩玄魏延归降！

烈日悬空，热浪翻滚。

长沙城外数里平原之上，五千精锐校刀手列成坚不可摧的铁壁大阵。

关羽身披绿袍金甲，按刀立马于中军帅旗之下。赤兔胭脂马昂首喷吐粗重白汽，那柄重达八十二斤的青龙偃月刀斜插于马侧，刀刃在刺目的烈日下吞吐着令人心悸的森森寒芒。

高耸险要的长沙城楼之上，太守韩玄面相凶残，三角眼中闪烁着狂暴的戾气，跳脚指着城下汉军破口大骂：“狂妄刘备，敢犯我长沙疆界！何人敢出城斩杀关羽，本官重赏千金！”

“韩太守休惊，有老夫在，定叫来犯之敌有来无回！”

一声苍劲如铜钟洪鸣的沉喝自敌楼中骤然炸响。只见城门大开，吊桥轰然落下，一员白发老将跃马挺刀，风驰电掣般杀出城关！

老将虽年过六旬，但生得面如重枣，二目如电，银白长须飘洒胸前，浑身筋肉如古树老藤般虬结盘根！手中一口沉重古朴的九凤朝阳刀泛着青幽光芒，坐下一匹神骏的黄骠透骨龙战马。

正是荆襄武道第一神话——老将黄忠黄汉升！

关羽凤目微眯，凝视着眼前这位虽然须发皆白、但周身气血浩瀚如海的当世虎将，心中暗赞一声，抱拳沉声道：“汉升将军名震荆襄，关某仰慕已久。为何屈身事韩玄这等暴虐无道之徒？我家兄长乃大汉皇叔，仁德布于四海。老将军何不顺天应人，早降皇叔，以全万世忠名？”

黄忠横刀大笑，豪气干云：“关云长！食君之禄，忠君之事！老夫生食汉粟，守土有责，何须多言！来来来，且教老夫领教领教你那青龙偃月刀的绝世锋芒！”

“好！某便领教老将军通神刀法！”

关羽长啸一声，双腿一夹赤兔马，赤兔马如离弦血箭般暴射而出！青龙偃月刀挟带着撕裂虚空的恶风，泰山压顶般当头斩落！

黄忠面不改色，双臂青筋如蛟龙暴突，九凤朝阳刀化作一道青色闪电迎风撩起！

“当————！！”

一声尖锐至极的金铁交击巨响撕裂天地，狂暴的气浪将周围数十步内的飞沙碎石尽数荡平！两军阵前数万将士只觉耳膜剧痛，呼吸为之窒息！

“好刀法！”

“再来！”

两员当世绝顶战将杀在一处，刀光霍霍如漫天飞雪，马蹄翻飞似狂雷骤雨。一人如怒龙翻江倒海，一人如苍鹰搏击长空！

转眼之间，双刀连环碰撞百余合，战得难分难解，竟不露丝毫破绽！两军擂鼓的军士双手酸软，直看得目瞪口呆！

战至百合开外，黄忠见关羽刀法严整如铁壁铜墙，勒马假作不敌，拖刀往本阵便走。关羽策马急追，孰料黄忠战马前蹄忽然踩入深泥洼坑，悲嘶一声骤然失蹄倒地！

黄忠猝不及防，沉重的身躯狠狠摔落尘埃，九凤朝阳刀脱手飞出数丈开外！

长沙城头韩玄吓得尖声怪叫，汉军阵营爆发出惊天动地的欢呼！

赤兔马风驰电掣般扑至，然而那柄足以开山碎石的青龙偃月刀，却在黄忠咽喉上方三寸之处硬生生悬停！

关羽立马按刀，居高临下俯视黄忠，长髯微抚：“黄汉升！某不杀失马失兵之人！速速回城换马，明日再战！”

城头汉军爆发出雷鸣般的喝彩，诸将无不为关羽这等千古义气深深折服。论坛之中更是弹幕如瀑：【ID-三国考据狂】：这一声不杀失马之人，直接把关二爷的武德格局拉满了！这才是傲视天下的关云长！【ID-终极军武迷】：黄忠这等顶尖名将最重脸面与义气，关羽这一收刀，比斩了黄忠还要震撼人心！

黄忠翻身爬起，捡起战刀，看着关羽策马徐徐回阵的雄伟背影，老脸通红，心中羞愧感激难以言表，长叹一声回城。

次日清晨，两军再度列阵对峙。

城头之上，韩玄面色阴冷如毒蛇，咬牙切齿地逼近黄忠：“黄忠！今日出阵，休要再与关羽缠斗！你百步穿杨之术天下无双，诱他出阵，暗施冷箭射杀关羽！若敢失手，以通敌死罪论处！”

黄忠心中凄苦悲凉，默默提弓上马。

两军交战三十回合，黄忠勒马回奔，关羽纵马急追。眼见行至吊桥边缘，黄忠猛然回身，左手如托泰山，右手如抱婴儿，二石铁胎弓瞬间拉如满月！

雕翎破甲箭搭上弓弦，锋芒死死锁定关羽眉心！

然而，想起昨日关羽不杀之恩义，黄忠手指剧烈颤抖，终究不忍加害忠良。

“铮！！”

弓弦惊爆，宛若霹雳雷鸣！

那一支鸣镝狼牙箭撕裂空气，擦着关羽头顶呼啸而过，精准无误地将关羽赤红战盔上的红缨一箭射断！

关羽惊出一身冷汗，勒马摘下断缨，心中雪亮黄忠乃是报昨日不杀之恩，当即引军退后三里，不再追击。

然而，城楼上的韩玄见黄忠一箭射偏，顿时暴跳如雷，凶相毕露！

“匹夫！通敌卖城之贼！！”

韩玄狞笑着拔剑喝令左右刀斧手：“黄忠昨日不杀关羽，今日又射箭放水，分明私通刘备！来人啊！将这老贼拿下，推下辕门斩首示众！！”

数十名刽子手如狼似虎地扑上，将黄忠五花大绑，剥去衣甲押往市曹！

城中父老军民见老将军即将含冤受戮，无不捶胸顿足，哭声震天！

就在行刑台前刽子手高高举起鬼头大刀、正欲斩落的千钧一发之际，街道斜刺里骤然爆出一声撼天动地的炸雷怒吼：

“韩玄狗贼！残暴无道，残害忠良，今又欲斩荆襄柱石，天理难容！！”

一道黑色铁塔般的身躯如猛虎出闸般狂暴杀出！

只见一员黑甲大将豹头环眼，杀气冲霄，手中厚背重刀化作一道雪白匹练，瞬息之间将两名刽子手横腰斩为两段！

正是长沙牙门将军——魏延魏文长！

魏延振臂狂呼，声若滚雷：“黄老将军乃三军之胆、万民之望！韩玄暴虐，欲毁长沙！愿随我诛杀韩贼、迎刘皇叔入城者，皆随我来！！”

“诛杀韩贼！诛杀韩贼！！”

被压抑多年的数百守城士卒与数千愤怒百姓轰然响应，潮水般涌向太守府与城楼！韩玄吓得魂飞魄散，抱头鼠窜，被魏延拍马追上，手起刀落斩下首级，掷于市曹！

“开城门！迎皇叔！！”

厚重的长沙城门轰然大开，关羽引军策马入城，亲手割断黄忠身上的绳索。

正在此时，城外官道上骤然响起密集的马蹄声。一袭白衣胜雪的江澈与刘备，在数百轻骑护卫下星夜兼程自江陵疾驰而至！

刘备跌跌撞撞奔入堂内，双手死死扶住欲行跪拜大礼的黄忠，泪如雨下：“汉升老将军受苦了！备德薄才疏，得见老将军，三生有幸！”

江澈亦大步上前，亲切扶起魏延，拍着其肩膀赞叹道：“文长将军深明大义，雷霆一击除暴安良，真乃社稷栋梁之才！主公有文长与汉升相助，汉室大业何愁不成？！”

黄忠与魏延相视一眼，胸中滚烫热血沸腾，齐齐翻身拜伏在地：

“末将愿随主公与军师荡平天下，虽肝脑涂地，在所不辞！！”

至此，荆南四郡全盘平定！赤壁之后，刘备集团全据荆襄，三足鼎立之盛大基业彻底奠定！
