小爱音箱「被代理」底层黑幕与实操全手册

剥开“不破解怎么拦截指令”的黑盒：为什么它既能偷听转写，又能静音小爱？
核心揭秘：利用官方 App 对话记录的「云端时空差竞争」
💡 关键心智模型（直击你的最大疑惑）：
很多人的第一直觉是：“小爱音箱要听我的话，必须在音箱硬件上做中间人（MITM）或者改麦克风驱动”。
完全不是！音箱硬件依然 100% 跑原厂逻辑。网关实际上是利用了「小米手机 App 能够实时看到你和小爱聊了什么」这个官方自带特性！

🔍 核心两招：毫秒偷听 与 闪电捂嘴

第一招：冒充手机 App「偷看」你的转写记录

每次你对小爱说话，音箱会把声音传到小米服务器转成文本。你在手机上打开「小爱音箱 App」，在“对话记录”里能立刻看到自己刚才说的话。

网关（xiaogpt）就是在这个接口上“蹲点”：它拿着你的小米账号 Cookies，模拟手机 App，以每 0.3 秒一次的频率向小米云端轮询：

GET https://userprofile.mina.mi.com/device_profile/v2/conversation
Cookie: userId=你的账号; serviceToken=...

# 返回结果（0.3秒后刷出来）：
{
  "text": "问问 Hermes，今天股市怎么样？",  <-- 网关毫秒级抓到这行字！
  "timestamp": 1727914022
}

第二招：在小爱张嘴前，下发「闭嘴」指令（时空差竞争）

当小爱面对一个问答题时，小米官方云端需要调用搜索或问答服务生成回答音频推给音箱，通常需要 1~2 秒的准备时间音箱才会开始出声。

这就是网关的绝佳抢跑时间窗口！网关发现文字里带了触发词（比如 问问），在第 0.1 秒内直接调用官方播放器控制接口：

POST https://api.mina.mi.com/remote/ubus
# 动作：立即暂停当前播放器 / 音频流！
# 效果：直接掐断小爱原厂云端推下来的音频，让音箱瞬间闭嘴静音。

第三招：让 Hermes 思考，再命令小爱把文字「朗读」出来

音箱被强制闭嘴后，网关把这句话丢给本地 Hermes（ocx 10100 端口）。等大模型生成 80 字精炼答案后，网关调用小米官方的 TTS 朗读接口：

POST https://api.mina.mi.com/remote/ubus
# 参数：让小爱音箱朗读指定文本：
{
  "command": "text_to_speech",
  "text": "今天自选股表现稳健，整体微涨 0.8%..."
}

音箱收到官方服务器发来的合法“文本朗读”指令，自然就把 Hermes 的回答清晰念出来了！

⏱️ 毫秒级时间线（这一秒内究竟发生了什么？）

0.00 秒：你说话
“小爱同学，问问今天大盘怎么样？”
0.40 秒：小米云端转写完成
音箱把音频上传小米云，ASR 把语音转成文字，写入你的账号对话记录库。
0.45 秒：网关捕获，闪电捂嘴
网关监听到这条记录命中关键词 问问，立刻下发 ubus pause，小爱原声被强行截断，音箱保持安静。
0.50 秒 ~ 1.50 秒：Hermes 本地思考
Mac 本地 ocx (10100 端口) 调用大模型分析完毕，返回 80 字结论。
1.60 秒：小爱音箱开口发声
网关下发 text_to_speech，小爱音箱念出 Hermes 的回答。

⚖️ 为什么开灯、放歌完全不受影响？

指令 A：“小爱同学，开客厅灯”
1. 云端生成对话记录：“开客厅灯”
2. 网关看了一眼：没带触发词（没说“请/问问”）
3. 网关直接装聋作哑，完全不理会
4. 小米原生逻辑执行，客厅灯正常打开！
指令 B：“小爱同学，问问 今天天气”
1. 云端生成对话记录：“问问 今天天气”
2. 网关看了一眼：命中关键词「问问」！
3. 网关0.1秒下发静音打断原生播报
4. 网关转交 Hermes，随后用音箱朗读 Hermes 回复。

🚀 四步极简实操（立刻落地）

1 查音箱型号代码与 DID
pip3 install miservice_fork
export MI_USER="你的小米账号"
export MI_PASS="你的小米密码"
micli mina

记下输出中的 hardware（如 LX06）和 miotDID（如 570117702）。

2 安装 xiaogpt 网关
pip3 install -U "xiaogpt[locked]"
3 创建配置文件 ~/.hermes/xiaogpt.json
{
  "hardware": "LX06",
  "account": "你的小米账号",
  "password": "你的小米密码",
  "mi_did": "你的miotDID",

  "bot": "chatgptapi",
  "api_base": "http://127.0.0.1:10100/v1",
  "openai_key": "dummy",
  "gpt_options": {
    "model": "google-antigravity/gemini-3.8-flash",
    "temperature": 0.7
  },

  "prompt": "你是家庭助手 Hermes。请用口语化精炼中文回答，100字内，适合语音朗读，不要输出Markdown。",

  "use_command": true,
  "mute_xiaoai": true,
  "keyword": ["请", "问问", "Hermes", "帮我"],

  "tts": "mi",
  "stream": false
}
4 启动
xiaogpt --config ~/.hermes/xiaogpt.json
