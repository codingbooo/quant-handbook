小爱音箱 接入 Hermes 实操落地指南

零拆机 · 零刷机 · 双向对话与主动播报完整配置文件与实操脚本
已适配 ocx (127.0.0.1:10100) 本地中枢
核心原理一句话说明：
你的 Mac 上常驻一个极轻量的网关程序（xiaogpt）。当你说“请 / 问问”时，网关拦截该提问，发给 Mac 正在运行的 ocx / Hermes（端点 127.0.0.1:10100）进行思考，最后把回答下发给音箱朗读。日常说“开灯、放歌、定闹钟”，完全走原生小爱。

🛠️ 准备物料 (只需三样)

  • 小米账号与密码（用于授权网关监听音箱的 ASR 语音识别流）。
  • 小爱音箱硬件型号（如音箱底部的标签：LX06、L05B、L05C 等）。
  • 音箱的 Device ID (DID)（通过 1 行命令自动查询，无需手动找）。

🚀 四步实操操作手册

1 获取小爱音箱的 DID 与型号代码

在你的 Mac 终端中运行以下命令，安装官方小米协议库并登录账号列出你家里的音箱设备：

# 1. 安装小米协议 CLI 工具
pip3 install miservice_fork

# 2. 导出你的小米账号密码临时查设备 (查完即可 unset)
export MI_USER="你的小米账号或手机号"
export MI_PASS="你的小米密码"

# 3. 运行查询命令，获取设备列表
micli mina

终端输出样例：

[
  {
    "name": "小爱音箱Pro",
    "hardware": "LX06",       <-- 这就是硬件型号 hardware
    "miotDID": "570117702",   <-- 这就是音箱设备 ID mi_did
    "presence": "online"
  }
]

记下你打算接入的那个音箱的 hardware 与 miotDID。

2 安装 xiaogpt 网关核心组件

执行以下命令安装网关环境：

pip3 install -U "xiaogpt[locked]"
3 创建配置文件 xiaogpt.json

在你的主目录创建 ~/.hermes/xiaogpt.json，配置文件已为你对接好本机正在运行的 ocx (127.0.0.1:10100)：

{
  "hardware": "LX06",
  "account": "你的小米账号",
  "password": "你的小米密码",
  "mi_did": "你的miotDID",

  "bot": "chatgptapi",
  "api_base": "http://127.0.0.1:10100/v1",
  "openai_key": "dummy",
  "gpt_options": {
    "model": "google-antigravity/gemini-3.8-flash",
    "temperature": 0.7
  },

  "prompt": "你是家庭智能助手 Hermes。请用口语化、亲切自然、精炼的中文回答，字数控制在100字以内，适合语音朗读，不要输出Markdown或特殊排版字符。",

  "use_command": true,
  "mute_xiaoai": true,
  "keyword": ["请", "问问", "Hermes", "帮我"],

  "tts": "mi",
  "stream": false
}
参数解析（为什么这样配？）：
  • api_base: 直接指向本地 http://127.0.0.1:10100/v1，无需外网代理，零延迟直连主力模型。
  • keyword: ["请", "问问", "Hermes", "帮我"]: 核心隔离机制！ 只有说“小爱同学，问问今天大盘怎么样”时才会转交 Hermes；直接说“小爱同学开灯”，直接走米家原生智能，毫不影响全家日常。
  • mute_xiaoai: true: 命中关键词后，网关毫秒级静音小爱音箱的原厂回复，无缝播放 Hermes 的思考结果。
4 启动服务并测试交互

运行以下命令启动网关（前台测试）：

xiaogpt --config ~/.hermes/xiaogpt.json

现在对着小爱音箱说：

🗣️ 原生指令测试：
“小爱同学，现在几点了？” / “小爱同学，播放周杰伦”
👉 小爱原生秒回，网关完全忽略放行。
🤖 Hermes 联动测试：
“小爱同学，请问为什么天空是蓝色的？” / “小爱同学，问问 Hermes 今天股票如何？”
👉 小爱原生声音被静音，几秒后用小爱音箱语音播报 Hermes 的智能回答！

🔔 进阶玩法：Hermes 主动呼叫音箱播报 (广播模式)

除了等待你提问，Hermes 还能主动把你家的小爱当扬声器。例如在每天早盘、收盘或提醒典典时，由 Hermes 触发一段 Python 代码下发语音：

# 极简主动发声示例：让音箱主动说话
micli 570117702 "主人，今天A股收盘复盘已生成，自选股整体表现稳健。"

这可以无缝挂载到 Hermes 的 Daily Cron 定时任务中，每天准点在客厅自动播报！
