Mac 本地依赖任务远程调度 · 红蓝军对抗裁决报告

⚔️ 审查机制: 多模型红蓝对抗 (Claude Sonnet 4.6 vs Gemini 3.8 Flash) 🎯 核心标的: 番茄小说 Chrome 自动化 & 微信小程序 CLI 打版 📅 日期: 2026-10-13
🏆 红蓝对抗核心裁决结论

彻底否定「云端主动 Push」与「脆弱反向 SSH 隧道」。红方严苛证明：任何依赖从云端主动入站 Mac 的通道，在 Mac 合盖、Wi-Fi 漫游、NAT 会话超时与系统睡眠时均会发生致命半开假死。
裁定采用「控制反转（Pull 架构）+ 本地单向出网 Worker」为唯一物理可行终局方案：Mac 作为常驻 Worker 主动向云端轮询/挂载长长连接拉取任务，云端只维护持久化任务队列与租约心跳，彻底免疫断网、断电与 NAT 超时。

📊 4 大候选方案全维度技术对抗矩阵
方案架构 通信模式 合盖/休眠表现 TCC 权限/GUI 兼容 红蓝对抗裁定
方案 A：反向 SSH / autossh 云端 Push 入站 半开假死 TCP 挂死，云端无感知超时 无 GUI 远程 SSH 剥夺 AppleScript/Chrome 权限 [否决] 脆弱高危，运维噩梦
方案 B：Tailscale 虚拟内网 云端 Push 入站 网卡断电 守护进程挂起，虚拟 IP 不通 较复杂 需系统扩展与用户态代理配合 [否决] 合盖无法唤醒，非根本解
方案 C：云端 Headless / Linux CLI 全云端原生 7×24h 在线 物理不可能 微信开发者工具无 Linux 版；机房 IP 必封番茄账号 [绝杀] 违反平台客观物理铁律
方案 D (获胜)：单向 Outbound Pull Worker Mac Pull 出站 (WSS/HTTP) 天然解耦 离线时任务排队，开机瞬间秒级消费 原生继承 注册为 LaunchAgent，完美继承 Aqua 图形会话 [采纳] 唯一工业级正解
🚨 红方（Claude Sonnet 4.6）致命攻击证据链
[P0] 合盖休眠的 TCP 半开黑洞 (Half-open Connection)
MacBook 合盖后，macOS 内核切断网卡供电。反向 SSH 隧道在云端一侧仍处于 ESTABLISHED 状态（未收到 FIN 包）。云端 Agent 发送 AppleScript 执行指令时直接陷入 120 秒网络假死，导致 Telegram 会话卡死。
[P0] TCC 辅助功能权限的会话隔离陷阱
通过外部 SSH 隧道登入 Mac 的进程运行在非交互式守护会话中，macOS TCC 机制会直接拦截 tell application "Google Chrome" to execute javascript，抛出 Not authorized to send Apple events (-1743)，无法操作 Chrome。
[P0] 微信开发者工具与机房 IP 的绝对红线
腾讯官方从未发布 Linux 版微信开发者工具 CLI；番茄小说创作者后台针对数据中心机房 IP（腾讯云 ASN）实施了严格的指纹风控，云端无头请求必触发验证码甚至冻结创作者账号。
🛡️ 蓝方（Gemini 3.8 Flash）终局架构落地蓝图
系统拓扑结构与任务流转：
[ Telegram 用户指令 ] (例如: "修改番茄小说书名" 或 "打版小程序")
       │
       ▼
[ 云端 VPS: Hermes Agent ] ─── (检查租约) ───► [ Mac 租约心跳缓存 ]
       │                                             │
       ├─────────────────────────────────────────────┘
       │  • Mac 在线 (插电开机) ➔ 实时下发任务 ➔ 3秒内返回
       │  • Mac 离线 (合盖带走) ➔ 任务持久化入队 (带TTL) ➔ 立即秒级响应用户:
       │    "Mac当前离线，任务已安全挂起排队[#102]，开机联网后自动执行。"
       │
       ▼ (持久化队列: SQLite / JSONL)
[ 云端任务 Broker ]
       ▲
       │  (Mac 唤醒联网后，单向长轮询秒级拉取任务)
[ Mac: LaunchAgent Worker (com.hermes.worker) ]
       │
       ├─► 调度本地 Chrome (AppleScript 注入，天然享有已登录 Cookie)
       └─► 调度微信开发者工具 CLI (编译、预览、生成二维码)
       │
       ▼ (回传执行日志与产物)
[ 云端 VPS ] ─── (推送结果) ───► [ Telegram: 任务已完成，附二维码/报告 ]
🛠️ 极简落地执行路线（用户只需在 Mac 运行一次）
1
云端轻量 Broker 就绪
在云端开辟极简 HTTP 任务调度端点（/api/worker/poll 与 /api/worker/ack），自带 12 小时任务 TTL 与幂等防重入锁，杜绝重复执行。
2
Mac 端单文件 Worker 安装
一个约 80 行的轻量 Python 脚本，开机后在用户 Aqua 会话自动运行，主动向云端拉取任务。开盖联网即连，合盖断网自动休眠。
3
LaunchAgent 用户级自启注册
注册为 ~/Library/LaunchAgents/com.hermes.worker.plist，跟随用户登录桌面自启，彻底享有 macOS 本地辅助功能（Accessibility）与 AppleScript 执行权。
4
固定工位插电防休眠（可选）
若平时放在办公桌插电合盖充当服务器，只需一条原生命令 sudo pmset -c disablesleep 1，插电时永远在线，拔掉电源合盖放入包中依然正常休眠。
